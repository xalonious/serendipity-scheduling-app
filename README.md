# Serendipity Scheduling Site & Game API

A scheduling web application used to manage **staff shifts and trainings** for a **Roblox roleplay group**. The site allows staff members to view schedules, sign up for available trainings, and manage shifts in a centralized place rather than handling scheduling manually.

Alongside the website, the project includes a **backend API** that is also used by Roblox game servers. This API enables in-game features such as **special nametags, rotating staff tips, and permission-related checks**, allowing the website and Roblox games to stay in sync and share the same staff and scheduling data.
